# Preregistration v0 (S1-PII)

Committed before any S1 training run. Any later change is a new file (`v0.1.md`, ...) with a dated rationale; this file is never edited after the tag `prereg-v0`.

## Systems
- S1-PII v0: ModernBERT-large, joint typed BIOES + CRF, span confidence from constrained forward-backward marginals, per-type temperature, O-exit bias as the single recall knob. Three training variants: all-sources, no-Nemotron (LOBO), all-sources-minus-nothing for PII-TRACE (PII-TRACE is test-only in its public release, so no LOBO variant is needed). Three seeds each.
- Baselines (latest GLiNER models only), revisions pinned in `configs/baselines.yaml`:
  - GLiNER2-PII, `fastino/gliner2-privacy-filter-PII-multi`
  - NVIDIA GLiNER-PII, `nvidia/gliner-PII`
  - GLiNER2.5 base, `fastino/gliner2.5-base-v1`, zero-shot with core-8 label descriptions

## Headline test sets (C0 family)
`tab_direct` (test), `spy_medical`, `spy_legal`, `pii_trace`, `nemotron` (test; S1 scored with the no-Nemotron model; excluded for NVIDIA GLiNER-PII, which trained on it), `fresh_real`.
Test documents flagged by the leakage audit (`s1pii.audit.dedup`) against any training source are removed before scoring. The audit report is committed with results.

## PII set per benchmark
Type-agnostic. PII = spans mapped to a canonical type by `s1pii/taxonomy.py` at `MAP_VERSION = taxonomy-v0.1`. IGNORE regions are excluded from all metrics. TAB: DIRECT = PII, QUASI = IGNORE (headline), QUASI = PII in the secondary `tab_quasi` tier.

## Primary metric
Normalized partial AUC of best-achievable leak over over-redaction budgets in [0, 0.05], computed per `s1pii/eval/metrics.py` (alphanumeric characters, predictions expanded to whole words, scores on a 1/1000 grid, no interpolation; budgets beyond a system's reachable over-redaction use its lowest reachable leak). Lower is better.

## Claims
- **C0.** S1 has lower pAUC than every baseline on at least 4 of the 6 headline sets. Each win requires the paired cluster-bootstrap 95% interval of (S1 minus baseline) to exclude zero after Holm correction over 6 sets x 3 baselines = 18 comparisons (alpha 0.05). The S1 score is the mean over 3 seeds; the bootstrap is run on each seed and the reported p-value is the maximum over seeds (conservative). If Fresh-Real is not ready by week 6, the rule becomes 3 of the remaining 5, declared in the report.
- **C1 (descriptive).** Brier and adaptive ECE over the candidate set (floor 0.05, IoU 0.5) after identical per-type isotonic recalibration fitted on each dataset's calibration split for every system.
- **C2.** Propagation raises PII-TRACE multi-mention consistency; precision on propagated spans must be >= 0.90 or propagation is dropped.

## Operating points
(a) vendor default threshold (GLiNER2-PII 0.5, NVIDIA GLiNER-PII 0.3 per its card, GLiNER2.5 0.5; S1 0.5), (b) shared-dev threshold: lowest threshold with over-redaction <= 1% on the development split, same rule for all. Never tuned on test.

## Clusters
Bootstrap unit: `Doc.cluster_id` (TAB and SPY: document; PII-TRACE: conversation; Nemotron: domain|document_type family; Fresh-Real: source document).

## Adjudication
200 disagreement spans per headline set (stratified by type), blind to system identity, adjudicated by the author; headline reported raw and noise-corrected.
