# Preregistration v0 (S1-PII)

Committed and tagged `prereg-v0` before any S1 training run. Later changes go in a new file
(`v0.1.md`, ...) with a dated rationale; this file is not edited after the tag.

## Systems
- **S1-PII v0**: ModernBERT-large, joint typed BIOES + CRF, span confidence from constrained forward-backward marginals, O-exit bias as the single recall knob. Training variants: `all-sources` and `no-nemotron` (LOBO). PII-TRACE, SPY and TAB are never trained on. Three seeds per variant.
- **Baselines** (latest GLiNER models only; revisions pinned in `s1pii/configs/baselines.yaml`): GLiNER2-PII (`fastino/gliner2-privacy-filter-PII-multi`), NVIDIA GLiNER-PII (`nvidia/gliner-PII`), GLiNER2.5 base (`fastino/gliner2.5-base-v1`, zero-shot).
- **Queried labels**: every system covers the same core-8 + OTHER_PII types. The two PII-trained GLiNER models are queried with their own native label names for those types (listed with their canonical mapping in `s1pii/configs/baselines.yaml`), because they were trained on those names; the zero-shot GLiNER2.5 model gets the canonical names and descriptions in `s1pii/configs/labels.yaml`. The label lists are frozen with this prereg.
- **Emission floor**: every system emits all spans with score >= 0.01 (GLiNER `threshold=0.01`; S1 marginal >= 0.01), so each curve reaches as far as the model allows. Any system whose reachable over-redaction is below 0.05 on a set is flagged in the report.

## Headline test sets (C0 family)
`tab_direct` (test split), `spy_medical`, `spy_legal`, `pii_trace`, `nemotron` (test split; S1 scored with the `no-nemotron` model; NVIDIA GLiNER-PII excluded because it was trained on Nemotron-PII), `fresh_real`.
Calibration/dev splits: TAB uses its dev split; Nemotron uses a held-out slice of its train split that no S1 variant trains on; SPY, PII-TRACE and Fresh-Real are split hash-fixed at the cluster level with `calib_test_split(frac=0.2, salt="s1pii-calib-v0")`, and only the 80% test part is scored.
Leakage audit: `s1pii.audit.dedup.audit` of every training source against every test set (text MinHash Jaccard >= 0.8 verified exactly; skeleton identical hash or Jaccard >= 0.9). Whole clusters containing a flagged document are removed from headline scoring. A sensitivity analysis repeats C0 with the skeleton threshold at 0.7.

## Gold definition
Type-agnostic. PII = spans mapped to a canonical type by `s1pii/taxonomy.py` (`MAP_VERSION = taxonomy-v0.1`); IGNORE regions are excluded from every metric; predictions of types not in `taxonomy.ADMISSIBLE[dataset]` are dropped for every system. TAB: union over annotators, DIRECT = PII, QUASI = IGNORE (headline); a per-annotator sensitivity analysis and the `tab_quasi` tier (QUASI = PII) are reported as secondary. Disclosed asymmetry: Nemotron generic dates, cities and similar quasi-identifiers are IGNORE, while PII-TRACE `private_date` and TAB DIRECT dates are PII. PII-TRACE role prefixes ("User: ", "Assistant: ") are IGNORE.

## Primary metric
Normalized partial AUC (exact step-function integral) of the best-achievable leak over over-redaction budgets in [0, 0.05], per `s1pii/eval/metrics.py`: alphanumeric characters only, predictions expanded to alphanumeric runs, raw scores on a 1/1000 grid (no recalibration), no interpolation, budgets beyond a system's reachable over-redaction use its lowest reachable leak. Lower is better.

## Claims
- **C0.** For each (headline set, baseline) pair, a paired cluster bootstrap (10,000 resamples, `seed=0`) of mean-over-3-seeds pAUC(S1) minus pAUC(baseline), all seeds and the baseline evaluated under shared cluster weights (`bootstrap.paired_bootstrap_multi`). Family: 6 sets x 3 baselines minus the excluded Nemotron/NVIDIA pair = **17 comparisons**, Holm-corrected at alpha 0.05. A comparison is a win iff diff < 0 and Holm-adjusted p < 0.05. A set is won iff S1 wins against every baseline evaluated on it. **C0 holds iff at least 4 of 6 sets are won** (`bootstrap.c0_decision`). Per-seed results are reported as a sensitivity check. If Fresh-Real is not ready by week 6, the rule becomes 3 of the remaining 5 (16 comparisons), declared in the report.
- **C1 (descriptive).** Brier and adaptive ECE over the candidate set (floor 0.05, IoU 0.5, one-to-one matching by score) before and after identical per-type isotonic recalibration fitted on each set's calibration split, with cluster-bootstrap intervals.
- **C2.** Cross-mention propagation raises PII-TRACE multi-mention consistency (both `all_masked` and `conditional`); precision on propagated spans must be >= 0.90 or propagation is dropped.

## Operating points (secondary)
(a) vendor default threshold (GLiNER2-PII 0.5, NVIDIA GLiNER-PII 0.3 per its card, GLiNER2.5 0.5, S1 0.5); (b) shared-dev: the lowest grid threshold with over-redaction <= 1% on the calibration/dev split (`evaluate.tune_threshold`), same rule for all. Never tuned on test.

## Clusters
`Doc.cluster_id`: TAB and SPY document; PII-TRACE conversation; Nemotron `domain|document_type`; Gretel `document_type|expanded_type`; Fresh-Real source document.

## Adjudication
200 disagreement spans per headline set, stratified by type, blind to system identity; headline reported raw and noise-corrected.
